# Weather Analysis Program

## Overview
This project is a Structured Programming assignment that focuses on analyzing weather-related data to study patterns such as climate change trends, humidity levels, and temperature variations.

The program processes input data and performs calculations to generate meaningful insights about weather conditions over time.

---

## Objectives
- Analyze weather data inputs
- Calculate temperature trends over time
- Measure humidity levels and variations
- Identify possible climate change patterns
- Practice structured programming concepts

---

## Features
- Data input handling for weather parameters
- Temperature analysis and trend calculation
- Humidity level computation
- Basic climate change indicator analysis
- Structured programming approach using functions/modules

---

## Concepts Used
- Variables and data types  
- Conditional statements  
- Loops (for/while)  
- Functions / modular programming  
- Data processing and calculations  

---

## Technologies Used
-C++
